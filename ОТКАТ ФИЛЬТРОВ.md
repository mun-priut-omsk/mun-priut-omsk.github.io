# Как отменить новую фильтрацию

Перед доработкой сохранена Git-метка `before-catalog-filters-20261029` на коммите `d2c43b64e88eac18f8d2c0801a304f4fb5665e17`.

Чтобы отменить только эту доработку, не удаляя последующие изменения карточек:

1. В GitHub Desktop откройте вкладку **History**.
2. Найдите коммит **Add responsive catalog filters with URL state**.
3. Нажмите на него правой кнопкой и выберите **Revert Changes in Commit**.
4. Нажмите **Push origin**.

Можно также написать в чате «откати новые фильтры». Будет отменён коммит доработки, а не вся база. Если GitHub Desktop сообщит о конфликте, остановитесь и пришлите текст сообщения: не выбирайте удаление карточек или сброс всей истории.

Фото, оригиналы и данные собак в коммите фильтров не изменяются.
