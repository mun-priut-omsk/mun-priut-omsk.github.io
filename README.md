# Наши собаки

Публичный каталог собак на GitHub Pages. Исходная база: C052, 194 карточки, 3064 фотографии.

## Для владельца — будем идти по одному шагу

1. Создать бесплатный аккаунт на https://github.com/signup и подтвердить почту.
2. Сообщить в чате только логин. Пароль, одноразовые коды и секреты присылать не нужно.
3. Вместе создадим публичное хранилище сайта с именем `dogs` и загрузим готовый проект.
4. В настройках Pages выберем GitHub Actions. После успешной сборки появится адрес сайта.
5. Проверим сайт с телефона и домашнего интернета.
6. Отдельно подключим вход в Decap CMS. В подготовленном варианте GitHub Pages публикует каталог, а бесплатный Netlify-проект используется только для входа через GitHub. Публикация карточек не запускает платные публикации Netlify.

Не нужно сейчас выполнять все пункты: следующий шаг объясняется в чате после предыдущего.

## Что будет доступно редактору

Панель `/admin/`: кличка, описание, номер и цвет бирки, статус, добавление и перестановка фотографий. Сохранение записывает изменения в GitHub; затем сайт обновляется автоматически. До настройки входа панель честно показывает экран подключения.

Тренировочная панель `practice.html` есть только в локальной пробной сборке. Её изменения хранятся в браузере и не изменяют исходные файлы. В production эта панель не публикуется.

## Как устроены данные

- `content/dogs/*.json` — одна карточка в одном файле. Идентификаторы существующих собак сохранены.
- `static/media/` — большие версии фото, до 1800 пикселей, подготовленные из исходников.
- `static/thumbs/` — превью для списка.
- `static/media/` — также новые фотографии, загруженные через CMS. При сборке преобразуются в оптимизированные версии; необработанные загрузки на сайт не копируются.
- `settings.json` — публичные настройки, без секретов.
- `.local/` — локальная служебная информация; в GitHub не отправляется.
- `dist/` — готовый сайт; собирается автоматически и не коммитится.

## Для сопровождения

`python import_catalog.py` — одноразовый импорт из соседней папки `dog_catalog`; повторять после начала редактирования через сайт нельзя, иначе изменения редактора будут перезаписаны.

`python build.py` — локальный вариант с тренировочной панелью.

`python build.py --production` — сборка для публикации, без тренировки.

`python configure.py --owner USERNAME --repo dogs --auth-site NAME.netlify.app` — подключение публичных настроек, не секретов.

Не добавлять в публичное хранилище оригинальные архивы, журнал исключённых фото, локальные пути и резервные копии прежней базы. В проект уже перенесены только активные карточки и разрешённые фотографии.
