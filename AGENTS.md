# Единое оформление публичных страниц

- Все новые публичные страницы должны использовать одинаковые шапку и футер с главной `static/index.html`. Главная — образец HTML-разметки этих блоков; копируйте их целиком, сохраняя ссылки, адрес и подписи.
- Шапка оформляется общим `static/hero.css`, футер — `static/site-chrome.css`. Подключайте оба файла после базовых стилей. Не переопределяйте оформление шапки и футера в стилях отдельных страниц.
- Разрешается отмечать текущую ссылку меню `aria-current="page"`.
- При изменении общих блоков синхронизируйте разметку всех использующих их публичных страниц (сейчас `static/index.html`, `static/progulki.html`, `static/kak-vzyat-pitomca.html`, `static/peredat-pomoshch.html`, `static/stat-opekunom.html`). Служебный редактор и админка имеют свой интерфейс.
- Футер содержит название сайта волонтёров, ссылку `privacy.html`, группу `https://vk.ru/mun_priut_omsk` и строку «Адрес омского муниципального приюта - г. Омск, ул. 2я Учхозная, д.2А».
- Сохраняйте работу локального редактора, каталога и оригиналов. Публикационная сборка: `python build.py --production`. Изменения сохраняйте локальным коммитом; для публикации пользователь нажимает Push origin.
