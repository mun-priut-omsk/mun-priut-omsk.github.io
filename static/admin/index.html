Для владельца каталога

Карточки и оригиналы —
под вашим управлением.

Редактор работает на вашем компьютере. Новые фото сохраняются там в исходном качестве; на сайте используются отдельные версии для просмотра.

  1. Откройте папку каталога dog_site и запустите Редактор собак.cmd.
  2. Выберите собаку или создайте новую карточку. Можно добавлять фото, менять их порядок и переносить к другой собаке.
  3. Нажмите Сохранить карточку, затем Push origin в GitHub Desktop. Сайт обновится автоматически.

В редакторе также можно собрать архив оригиналов по актуальным карточкам GitHub. Если правили карточки прямо на GitHub, сначала нажмите «Обновить с GitHub».
